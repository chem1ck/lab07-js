# Практична робота 5-6: Основи CSS

## Опис проєкту
Цей проєкт — базова багатосторінкова веб-сторінка (Головна, Про мене, Контакти), створена для демонстрації навичок роботи з HTML та CSS. 

## Що було стилізовано
- Налаштовано базову дизайн-систему (кольори, шрифти) за допомогою CSS-змінних.
- Створено навігацію з використанням Flexbox.
- Оформлено контент: заголовки, таблиці, форми, зображення та медіаелементи (відео/аудіо).
- Забезпечено адаптивність сайту (Media Queries) для коректного відображення на мобільних пристроях.

## Як запустити
1. Завантажте всі файли проєкту.
2. Відкрийте файл `index.html` у будь-якому сучасному браузері (наприклад, Chrome, Safari або Edge).
