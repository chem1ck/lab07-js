# Практична робота №11-12: REST API та CRUD-операції

## 📝 Опис проєкту
Цей проєкт демонструє взаємодію фронтенд-частини з REST API. Статичний макет було перетворено на повноцінний клієнт, який виконує CRUD-операції (Create, Read, Update, Delete) з використанням локального мок-сервера `json-server`. 

**Тема роботи:** HTTP-запити (GET, POST, PATCH, DELETE), fetch(), керування станами UI та модульний JavaScript.

## 🚀 Реалізований функціонал
1. **API-шар (Модульність):** Усі HTTP-запити винесено в окремий модуль `api.js` за допомогою `fetch()` та `async/await`.
2. **GET (Отримання даних):** Динамічний рендеринг списку послуг з бази даних `db.json`. 
3. **POST (Створення):** Можливість додавати нові записи через валідовану модальну форму.
4. **PATCH (Редагування):** Отримання даних конкретного запису, заповнення форми та оновлення інформації на сервері.
5. **DELETE (Видалення):** Видалення карток із попереднім підтвердженням дії (confirm).
6. **Керування станами UI:** Візуалізація станів `loading`, `error`, `empty` та відображення Toast-повідомлень (success/error повідомлення) після кожної операції.
7. **Фільтрація та сортування:** Реалізовано пошук, фільтр за категоріями та сортування за ціною за допомогою параметрів `URLSearchParams` (`q`, `category`, `_sort`, `_order`).

## 🛠️ Інструкція із запуску проєкту

Для коректної роботи проєкту необхідно запустити два сервери: один для бази даних (REST API), інший — для фронтенду.

### Крок 1: Запуск сервера бази даних (json-server)
1. Відкрийте термінал у кореневій папці проєкту.
2. Якщо `json-server` ще не встановлено, виконайте команду:
   \`\`\`bash
   npm install -g json-server
   \`\`\`
3. Запустіть сервер командою:
   \`\`\`bash
   json-server --watch db.json --port 3000
   \`\`\`
   *Сервер повинен працювати у фоновому режимі (термінал не закривати).*

### Крок 2: Запуск фронтенду
1. У Visual Studio Code натисніть правою кнопкою миші на файл `index.html`.
2. Оберіть **"Open with Live Server"**.
3. Проєкт відкриється у браузері, підтягне дані з порту 3000 та буде готовий до роботи.
