# [cite_start]Практична робота №9–10: Асинхронна робота з даними у JavaScript [cite: 1]

## 📝 Опис проєкту
[cite_start]Цей проєкт є логічним продовженням розробки мінісайту, який було трансформовано зі статичного макету на динамічний вебпроєкт (data-driven)[cite: 4, 6]. [cite_start]Контент каталогу послуг більше не дублюється в HTML вручну, а асинхронно завантажується із зовнішнього локального конфігураційного файлу форматі JSON, динамічно рендериться в браузері та гнучко керується за допомогою інтерактивних елементів інтерфейсу[cite: 6, 51, 62].

[cite_start]**Тема роботи:** fetch(), JSON, рендеринг каталогу та керування станом інтерфейсу[cite: 2].

---

## 🚀 Реалізований функціонал

[cite_start]У межах практичної роботи було успішно реалізовано повний користувацький сценарій взаємодії з даними[cite: 78]:

1. [cite_start]**Асинхронний запит (Fetch API):** Отримання масиву об'єктів з локального файлу `services.json` за допомогою `fetch()` із застосуванням сучасного синтаксису `async/await` та обробкою виключень через блоки `try/catch`[cite: 9, 52, 53, 85, 86].
2. [cite_start]**Керування станами інтерфейсу (UX):** [cite: 93]
   * [cite_start]**Loading State:** Візуальний індикатор (спінер) під час очікування завантаження даних[cite: 54, 90].
   * [cite_start]**Error State:** Текстове повідомлення для користувача в інтерфейсі у випадку збою мережі або відсутності файлу[cite: 55, 87, 92].
   * [cite_start]**Empty Result State:** Повідомлення про відсутність результатів, якщо жоден елемент не відповідає критеріям пошуку чи фільтрації[cite: 56, 107].
3. [cite_start]**Динамічний рендеринг:** Генерація семантичних карток послуг (зображення, категорія, назва, опис, вартість) "на льоту" через маніпуляції з DOM без хардкоду в HTML-файлі[cite: 11, 62, 94, 96].
4. **Комплексна фільтрація та пошук:**
   * [cite_start]Реалізовано "живий пошук" (Live-search) у реальному часі за назвою та описом послуги[cite: 99, 100, 101].
   * [cite_start]Додано фільтрацію за категоріями (Кібербезпека, Розробка, Консалтинг) через випадаючий список[cite: 104, 105].
   * [cite_start]Пошук та фільтри працюють скоординовано, не скидаючи стани один одного[cite: 102, 201].
5. [cite_start]**Сортування даних:** Можливість впорядкування карток за алфавітом (А-Я), а також за зростанням або спаданням ціни[cite: 109, 110, 111]. [cite_start]Logic сортування винесено в окрему чисту функцію[cite: 112].
6. [cite_start]**Пагінація (Показати ще):** Порційне відображення карток (по 4 штуки на сторінку) для оптимізації простору сайту[cite: 120, 123].
7. [cite_start]**Збереження обраного (LocalStorage):** Можливість додавати послуги в "Обране" (інтерактивна зірочка) із тривалим збереженням ідентифікаторів у `localStorage` після перезавантаження сторінки[cite: 15, 61, 114, 116].
8. **Інтерактивні UI-компоненти:**
   * [cite_start]Модальні вікна для детального перегляду інформації про послуги та секретного контенту[cite: 19, 124, 125, 128].
   * [cite_start]Акордеони для структурованого відображення навичок[cite: 314].
   * [cite_start]Перемикач світлої/темної теми сайту із запам'ятовуванням вибору користувача[cite: 19, 264].
9. [cite_start]**Валідація форми та Чернетка:** Перевірка полів введення (Ім'я, Email, повідомлення) перед відправкою, живий лічильник символів у `textarea` та автозбереження тексту форми в `localStorage` на випадок випадкового оновлення сторінки[cite: 4, 19, 386].
