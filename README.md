# Практична робота № 7-8: Інтерактивність мінісайту на JavaScript

Цей проєкт є багатосторінковим мінісайтом, функціонал якого розширено за допомогою клієнтського JavaScript. Основна мета роботи — додати інтерактивні елементи, забезпечити обробку подій та налаштувати збереження стану інтерфейсу користувача.

## 🚀 Реалізований функціонал

У межах роботи було реалізовано такі механіки:

1.  **Навігація**: Динамічне підсвічування активного пункту меню залежно від поточної сторінки.
2.  **Мобільне меню**: Адаптивне меню-бургер, що коректно відкривається та закривається на мобільних пристроях.
3.  **Темна/світла тема**: Перемикач оформлення з використанням `localStorage` (вибір теми зберігається після оновлення сторінки).
4.  **Кнопка «Вгору»**: Кнопка, що з'являється при прокручуванні сторінки та забезпечує плавний скрол до початку.
5.  **Динамічний футер**: Автоматичне оновлення року в підвалі сайту за допомогою JS.
6.  **Акордеон**: Інтерактивний блок для приховування/показу додаткового контенту.
7.  **Фільтрація контенту**: Можливість сортування карток послуг/проєктів за категоріями за допомогою `data`-атрибутів.
8.  **Модальне вікно**: Вікно з контентом, що відкривається за кліком та закривається натисканням на кнопку або оверлей.
9.  **Форма зворотного зв'язку**:
    * Валідація полів (ім'я, email, текст повідомлення).
    * Лічильник символів для текстового поля.
    * Автозбереження чернетки в `localStorage`.
    * Виведення результату відправки форми без перезавантаження сторінки через `FormData`.

## 🛠 Технології

* **HTML5** (семантична верстка)
* **CSS3** (Flexbox/Grid, адаптивність)
* **JavaScript (ES6+)** (DOM API, LocalStorage, події)
